FOTO YANG DIPAKAI APLIKASI
==========================
  profile.jpeg      -> foto profil bulat (halaman 1)
  portfolio_1.png   -> karya 1 (halaman 5)
  portfolio_2.png   -> karya 2 (halaman 5)
  portfolio_3.png   -> karya 3 (halaman 5)

Mau ganti foto? Timpa file dengan nama yang sama, atau ubah path-nya
di lib/data/profile_data.dart. Setelah itu stop lalu run ulang aplikasi
(bukan hot reload).
